## 2. 표기 규칙

| 표기 | 의미 |
|------|------|
| **[확정]** | 사용자가 직접 답변해 확정한 사항 |
| **[위임 결정]** | 사용자가 "추천/비교 후 결정"으로 위임한 사항. 근거를 문서에 남기며, 승인 시 최종 확정 |
| **[제안]** | 설계자가 제안한 값/방식. 승인 전까지 확정 아님 |
| **[미확정]** | 아직 결정하지 않은 사항. 후보와 비교만 제시. 임의로 확정하지 않음 |

우선순위: **P0** = MVP(1차 출시 필수) / **P1** = MVP 직후 확장 / **P2** = 장기 또는 사전 조사 필요 / **보류** = 요구가 생길 때 검토

## 4. 조사로 새로 발견된 중대 사항 (자세한 내용: [11 문서](11-legal-and-compliance-research.md))

1. **Pokémon TCG API는 폐기 예정, 2027-03-01 종료.** **개발·1차는 이 무료 API/덤프로 적재**하고 앱은 DB만 조회. 유료 Scrydex는 쓰지 않음. 종료 전에 후속 소스 재결정 → **DEC-16 (일부 확정)**
2. **포켓몬 측은 IP 사용 요청을 검토하지 않으며 프로젝트에 사용하지 말 것을 요청**한다. **1차는 무광고**로 위험을 낮추지만, 무광고 스토어 출시+카드 이미지도 중~높음 위험 → **DEC-13 잔여**
3. **1차 광고 없음** → 가족 정책의 광고 SDK 요건은 보류. 전연령 대상이면 분석 SDK 등 다른 요건은 남을 수 있음 → **DEC-17 잔여(연령 서버 검증)**
4. **만 14세 미만은 가입 불가·게스트 열람만**, 출시 국가는 **한국** [확정]
5. 새 Supabase 프로젝트 **`card-dex` 생성 완료**(월 $0). 무료 플랜은 7일 저활동 시 정지. 스키마는 설계 승인 전까지 만들지 않음
6. 스토어에 비슷한 앱이 많다는 것은 합법성의 근거가 아님 (11 §7)

## 7. 승인 절차

1. 사용자가 문서 전체를 검토하고 수정 의견/질문 답을 준다.
2. 수정 반영 후 남은 결정(DEC-13 최종 앱 이름, DEC-15, 연령 서버 검증 등)은 출시 전/해당 단계에서 확정한다.
3. 사용자가 **명시적으로 승인**하면 `09-development-plan.md`의 PH-1부터 개발을 시작한다.
4. 승인 전까지 앱 소스 코드, 설정 파일, 스캐폴딩, **Supabase 스키마 마이그레이션**을 하지 않는다. (빈 프로젝트 `card-dex` 생성만 4차에서 사용자 요청으로 완료)
